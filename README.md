# Flip Game 🎴

An interactive and responsive memory card game built using **HTML, CSS, and JavaScript**. The game features three difficulty modes, a scoring system that tracks your best scores using **local storage**, and a smooth flipping animation.

## 🎮 Features
- **Responsive UI**: Works seamlessly on phones, tablets, and desktops.
- **Three Modes**: Easy, Medium, and Hard.
- **Flipping Animation**: Smooth and visually appealing.
- **Scoring System**: Stores and updates your win and lose score in **local storage**.
- **Win Condition**: Unflip all the matching cards win.

## 🛠️ Technologies Used
- **HTML**: Structure of the game.
- **CSS**: Styling and responsive design.
- **JavaScript**: Game logic, animations, and score tracking.

## 🚀 How to Play
1. Click on any card to flip it over.
2. Match two identical cards to keep them open.
3. Complete all matches to win the game.
4. The game automatically updates your win and lose score in **local storage**.
5. The game contains a timer also, in the given time you have to complete it otherwise you will lose the game.

## 📂 Installation
1. Clone the repository:
